# Матрица Судьбы

![Обложка проекта](docs/assets/poster.webp)

**Личный расчёт и совместимость**

Калькулятор по дате рождения: личная матрица, совместимость, разделы трактовок, прогноз и экспорт результата.

**Тип:** Статический сайт · исходная версия · **Версия:** 1.0.0 · **Документация сверена:** 2026-10-08.

[Версии и скачивание](docs/RELEASES.md) · [Аудит и предложения](docs/AUDIT.md) · [Исходники](https://github.com/kipingame-cell/site2) · [Сборки](https://github.com/kipingame-cell/site2/actions)

## Возможности

- Лендинг и отдельный экран расчёта.
- Восьмиконечная SVG-матрица, личный расчёт и совместимость.
- Локальные таблицы трактовок с кратким встроенным fallback.
- Экспорт и печать результата; библиотека PDF находится в public/vendor/.
- Запуск без npm-зависимостей на Node.js 18+.

## Запуск и проверка

```bash
node server.js
# http://localhost:3000
# Проверки в отдельном терминале:
npm test
```

Для обычного запуска таблицы уже находятся в `public/db/`; приватный `site` не нужно публиковать. GitHub Pages использует существующий workflow `.github/workflows/static.yml`.

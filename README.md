# ✦ Матрица Судьбы — бесплатный калькулятор онлайн

Полноценный сайт расчёта **Матрицы Судьбы** по дате рождения: личный разбор,
совместимость пары, матрица здоровья по чакрам, прогноз по годам и «Выход в плюс» —
с полной базой трактовок 22 арканов и красивой печатью результата в PDF (А4, ч/б).

**Сайт:** https://kipingame-cell.github.io/site2/

## Что внутри

- **Лендинг** (`index.html`) — описание метода, статичная матрица-пример,
  22 аркана с картинками, программы и триады, чакры, кнопка «Начать расчёт».
- **Калькулятор** (`app.html`) — барабанчики выбора даты, классическая
  восьмиконечная октаграмма (SVG), 14 разделов личного разбора и 10 разделов
  совместимости: портрет, задача души, визитка, таланты, детство и родители,
  деньги, отношения, программы, род, кармический хвост, предназначения,
  здоровье, прогноз по годам, выход в плюс.
- **Печать / PDF** — «дорогой» чёрно-белый формат А4: рамка с орнаментом
  на каждой странице, первая страница — логотип + матрица в отдельной рамке,
  вторая — чакры в собственной рамке, каждый раздел с нового листа,
  карточки не разрываются между страницами. Готово для платного PDF.
- Весь расчёт — локально в браузере, даты никуда не отправляются.

## Запуск локально

```bash
node server.js          # http://localhost:3000
PORT=8080 node server.js
```

Нулевые зависимости — только Node.js 18+. Сайт полностью статический,
подходит для GitHub Pages из коробки (ветка `main`, папка `public` → корень).

## Тесты

```bash
node tests/matrixCore.test.mjs   # расчётное ядро (формулы заморожены)
```

## Импорт полной базы трактовок

База (~59 файлов: личные зоны, здоровье по чакрам, совместимость, родовые
программы) живёт в приватном репозитории `site` и подтягивается автоматически:

1. Временно сделай репозиторий `site` публичным (Settings → Danger Zone → Change visibility).
2. Здесь в `site2`: вкладка **Actions → «Import DB from site repo» → Run workflow**.
3. Верни `site` в приватный режим.

До импорта сайт уже работает на встроенной краткой базе — бейдж в шапке
показывает, какая база активна.

## Деплой на свой домен

```bash
node server.js            # или pm2 / systemd
```

Nginx проксирует на порт 3000 — готовый конфиг в `deploy/nginx.conf`.

# Проверка программ — 8 октября 2026

Для 10.06.2006: КХ 9–15–6 — «Мир страстей и сказок», также «Страсть или любовь». Личный талант K = red(месяц + центр) = red(6 + 3) = 9: Отшельник, исследование, обучение и передача знаний. Верхняя линия 6–15–9 сохранена: её геометрические точки совпадают с диаграммой matriza-sydbi.ru. Она больше не выдаётся за расшифровку личного таланта.

Исправлены: сортировка чисел хвоста вместо точного/зеркального поиска; переименование программы общим справочником; генерация отсутствующих программ; дублирование баннера хвоста. Название и текст теперь берутся из одной записи. Текст КХ и описание таланта 9 изложены своими словами по открытым материалам. Для отсутствующей комбинации возвращается null; отдельные карточки арканов остаются доступны.

# Проверка программ — 8 октября 2026

Исправления применяются ко всем датам. Автоматическая проверка перебирает все 146 462 допустимые даты за 1800–2200 годы: все получаемые КХ входят в закрытый каталог из 26 записей, каждый личный талант имеет одну из 22 собственных трактовок. Это проверка покрытия и выбора записей, а не независимая экспертиза всех текстов старой базы.

КХ выбирается по точному порядку чисел, затем по зеркальному, только если отдельной точной записи нет. 18–9–9 «Отшельник» и 9–9–18 «Волшебник» имеют разные записи. «Одинокая женщина» перенесена на правильный код 9–12–3; ошибочные 3–9–12 и 22–10–19 удалены. Название и текст берутся из одной записи, синтетические названия и трактовки отсутствующих программ отключены.

Личный талант рассчитывается по внутренней точке верхнего луча K = red(B + E). Для всех 22 энергий добавлены краткие отдельные трактовки. Верхняя линия из трёх чисел отображается отдельно от личного таланта. В 10.06.2006: КХ 9–15–6 «Мир страстей и сказок (Страсть или любовь)», личный талант 9, верхняя линия 6–15–9.

Код отношений исправлен на M–R1–R: внутренняя точка нижнего луча, центр канала отношений, вход в канал. Для 10.06.2006 это 9–11–20. В совместимости коды берутся из уже рассчитанных точек парной матрицы, без повторного расчёта новой матрицы по её углам.

Проверки: 23 теста в каждом репозитории; полный перебор дат; точные записи всех 26 КХ; отдельные записи всех 22 талантов; различение совпадающих зеркальных КХ; пути программ в личной и парной матрице; отсутствие выдуманной трактовки неизвестных комбинаций.

Ограничение: исторические таблицы остальных разделов всё ещё имеют пропуски; в site3 часть файлов этих таблиц отсутствует. Для отсутствующей программы возвращается null, а отдельные карточки арканов остаются доступны. Новые трактовки личного таланта и каталог КХ от этих файлов не зависят. Полная проверка всех текстов исторических таблиц не выполнена.

# Матрица Судьбы для Android 1.0.0

- Android 8.0 и новее; APK 3,5 МБ.
- Личная матрица, совместимость и трактовки работают без интернета.
- Сохранение PDF через системное окно Android, отправка карточки PNG.
- Исправлены родовой центр, родовые линии, возрастное кольцо и подписи точек.

Пакет: `ru.kipin.matrix`, versionCode: 100. Это та же подписанная сборка, которая выдана ранее: удалять её перед установкой не требуется.

Промежуточные возраста в прогнозе рассчитаны приближённо. Исторические тексты трактовок не прошли полную сверку с авторскими материалами Ладини.
